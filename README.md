# Portfolio - Pitois Bastian

Bienvenue sur mon portfolio en ligne ! Ce site a été conçu dans le cadre de mes études en BUT Réseaux et Télécommunications. Il présente mon parcours, mes compétences, ainsi qu’une sélection de projets réalisés durant mes semestres universitaires.

## 🔗 Lien de démo

> [https://patatecosmique.github.io/portfolio](https://patatecosmique.github.io/portfolio)

## 📁 Structure du projet

```plaintext
.
├── index.html             # Page d'accueil
├── projets.html           # Liste des projets réalisés (Semestre 1 & 2)
├── projet-detail.html     # Détail individuel d'un projet (chargement dynamique via JS)
├── css/
│   └── style.css          # Feuille de style principale
├── JS/
│   ├── script.js          # Scripts globaux (ex: animation de fond)
│   └── projet-detail.js   # Chargement dynamique des contenus des projets
└── assets/                # (optionnel) Images, icônes, etc.
````
## 🧠 Fonctionnalités

- Page d'accueil avec présentation personnelle.
- Liste de projets organisée par semestre.
- Pages de détail dynamique pour chaque projet (via `projet-detail.js`).
- Section **Compétences** (non fournie ici mais prévue dans la navigation).
- Animations de fond avec `<canvas>` pour améliorer l’esthétique.

## 📌 Technologies utilisées

- **HTML5 / CSS3**
- **JavaScript Vanilla**
- **Font Awesome** pour les icônes
- **Responsive Design** (via `viewport`)
